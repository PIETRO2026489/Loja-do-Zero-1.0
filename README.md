Loja-do-Zero
Jogo feito por Pietro, apenas por diversão LOJA DO ZERO

Jogo 2D de gerenciamento em Python + Pygame. O jogador começa com R$ 100 e transforma um pequeno mercadinho em uma Loja Premium.

Sistemas

10 produtos e desbloqueios por nível

estoque e vendas automáticas

clientes com comportamentos diferentes

8 melhorias

4 tipos de funcionários

eventos aleatórios

missões e conquistas

satisfação, confiança e limpeza

decoração

gráficos e histórico

Salvar JSON/manual

tutorial

Rodar

pip install -r requirements.txt python main.py

controles

1-8 menus, A/D produto, Q compra 5, W compra 10, S venda teste, F5 salvar, F9 carregar, ESC voltar/pausar.

O arquivo principal foi organizado em repositórios para facilitar expansão e manutenção.
